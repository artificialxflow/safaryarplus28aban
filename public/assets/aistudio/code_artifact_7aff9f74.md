# 📋 چک‌لیست جامع طراحی و پیاده‌سازی پلتفرم «سفریار پلاس» (SafarYar Plus)

این سند شامل نقشه راه گام‌به‌گام و عملیاتی برای طراحی رابط کاربری (UI/UX)، توسعه فرانت‌اند واکنش‌گرا (Responsive) و پیاده‌سازی تعاملات یکپارچه سامانه گردشگری، رزرواسیون و مالی آژانس مسافرتی است.

---

## فاز ۱: راه‌اندازی معماری پایه، هویت بصری و زیرساخت RTL
- [ ] ایجاد ساختار پایه فایل پروژه (`index.html`) با تنظیمات استاندارد HTML5 و متاتگ‌های Viewport برای نمایش صحیح در موبایل.
- [ ] تنظیم ویژگی `dir="rtl"` و `lang="fa"` در تگ اصلی `<html>` برای راست‌به‌چین‌سازی کامل تمام المان‌ها و جریان صفحه.
- [ ] فراخوانی فونت استاندارد و خوانای فارسی **Vazirmatn** از Google Fonts و تنظیم سلسله‌مراتب تایپوگرافی (تیترها، متن‌ها، اعداد و جداول).
- [ ] اتصال کتابخانه **Tailwind CSS** (از طریق CDN) و پیکربندی متغیرهای رنگی اختصاصی برند:
  - [ ] رنگ اصلی هواپیمایی: آبی لاجوردی عمیق (`#0F4C81` یا `blue-900`).
  - [ ] رنگ بخش تورهای زیارتی و سیاحتی: سبز زمردی (`#059669` یا `emerald-600`).
  - [ ] رنگ دکمه‌های فراخوان (CTA) و هشدارهای مالی: نارنجی/طلایی (`#F59E0B` یا `amber-500`).
  - [ ] پس‌زمینه تم روشن (Light Mode) با کادرهای مشخص (`border`) و سایه‌های ظریف برای تفکیک واضح بخش‌ها.
- [ ] افزودن کتابخانه آیکن‌های مدرن (**Lucide Icons** یا **FontAwesome**) و آماده‌سازی ایموجی‌های کاربردی.
- [ ] طراحی **نوار جابه‌جایی سریع (Top Switcher Bar)** در بالاترین نقطه صفحه برای سوئیچ آنی بین «نمای مشتریان (سایت آژانس)» و «پنل مدیریت یکپارچه (Admin Dashboard)».

---

## فاز ۲: طراحی و پیاده‌سازی نمای مشتریان (وب‌سایت اصلی آژانس - ۷ صفحه)
- [ ] پیاده‌سازی سیستم مسیریابی سمت کلاینت (SPA Routing / Tab Switching) با Vanilla JS برای جابه‌جایی روان بین ۷ صفحه بدون رفرش شدن صفحه.
- [ ] طراحی هدر (Header) و منوی ناوبری واکنش‌گرا شامل منوی همبرگری کشویی (Drawer) برای موبایل، لوگو و دکمه ورود/پیگیری رزرو.
- [ ] **۱. صفحه اصلی (Home):**
  - [ ] طراحی هیرو سکشن (Hero Section) با تصویر باکیفیت آنلاین و باکس جستجوگر هوشمند تور و پرواز (مبدا، مقصد، تاریخ، تعداد نفرات).
  - [ ] بخش دسته‌بندی سریع تورها (تورهای داخلی، خارجی و تورهای زیارتی با نشان ویژه 🕋).
  - [ ] بخش پیشنهادهای شگفت‌انگیز و تورهای لحظه آخری با شمارشگر یا برچسب تخفیف.
  - [ ] اسلایدر یا گرید هتل‌های برتر و بخش نظرات مسافران برای اعتمادسازی.
- [ ] **۲. صفحه تورها (Tours Listing):**
  - [ ] پیاده‌سازی سیستم فیلتر پیشرفته (بر اساس نوع تور، بازه قیمت، مدت اقامت و مقصد) با JavaScript.
  - [ ] تفکیک بصری دو بخش مجزا: «تورهای ویژه آژانس» و «تورهای رسمی سازمان حج و زیارت (متصل به وب‌سرویس)».
- [ ] **۳. صفحه معرفی تور (Tour Details):**
  - [ ] طراحی گالری تصاویر تور، برنامه سفر روزبه‌روز (Timeline) و لیست خدمات تور (پرواز، هتل، بیمه، ترانسفر).
  - [ ] جدول انتخاب تاریخ حرکت و قیمت‌گذاری بر اساس نوع اتاق به‌همراه فرم رزرو سریع آنلاین.
- [ ] **۴. صفحه هتل‌ها (Hotels Listing):**
  - [ ] کارت‌های نمایش هتل‌ها با نمایش تعداد ستاره‌ها، موقعیت مکانی، امکانات کلیدی و فیلتر قیمت.
- [ ] **۵. صفحه معرفی هتل (Hotel Details):**
  - [ ] گالری تصاویر اتاق‌ها و لابی، لیست امکانات رفاهی، بخش موقعیت روی نقشه و جدول رزرو اتاق.
- [ ] **۶. صفحه درباره ما (About Us):**
  - [ ] معرفی تاریخچه آژانس، نمایشگر مجوزهای رسمی (بند الف، بند ب، سازمان حج و زیارت)، آمار و ارقام کلیدی و معرفی تیم.
- [ ] **۷. صفحه تماس با ما (Contact Us):**
  - [ ] کارت‌های اطلاعات تماس شعب، ساعات کاری، نقشه موقعیت دفتر مرکزی و فرم تعاملی ارسال پیام به پشتیبانی.
- [ ] طراحی فوتر (Footer) جامع و راست‌به‌چین شامل دسترسی سریع، نمادهای اعتماد و اطلاعات ارتباطی.

## فاز ۳: طراحی پنل مدیریت یکپارچه (Admin Dashboard & ERP)
- [ ] طراحی اسکلت پنل ادمین با سایدبار راست‌به‌چین (قابل جمع شدن در موبایل) و هدر داخلی پنل.
- [ ] **۱. داشبورد مدیریتی (نمای کلی یکپارچه):**
  - [ ] طراحی ۴ کارت آماری (KPI Cards) با رنگ‌بندی متمایز: کاروان‌های فعال، کل مسافران ثبت‌شده، بلیت‌های صادرشده امروز و تراز سود و زیان ماهانه.
  - [ ] پیاده‌سازی نمودارهای تحلیلی (با Chart.js یا نمودارهای میله‌ای CSS) برای نمایش سود هر تور و وضعیت صدور بلیت‌ها.
- [ ] **۲. مدیریت محتوای سایت (Dynamic CMS):**
  - [ ] ایجاد رابط کاربری (فرم‌ها و جداول) برای افزودن، ویرایش و حذف تورها و هتل‌های سایت مشتریان.
  - [ ] بخش تنظیمات اتصال وب‌سرویس (API) سازمان حج و زیارت با نمایش وضعیت اتصال (متصل/قطع).
- [ ] **۳. مدیریت کاروان‌ها و مسافران (هسته مرکزی داده‌ها):**
  - [ ] جدول لیست کاروان‌ها شامل کد کاروان، مقصد، تاریخ رفت و برگشت، هتل محل اقامت و نوار پیشرفت ظرفیت.
  - [ ] فرم ثبت مسافر جدید (ثبت یک‌باره اطلاعات: نام و نام خانوادگی، کد ملی، شماره پاسپورت، انتخاب کاروان).
  - [ ] پیاده‌سازی دکمه تعاملی **«✈️ انتقال به صدور بلیت»** در ردیف هر مسافر که اطلاعات او را مستقیماً به فرم صدور بلیت منتقل کرده و وضعیت بلیت را از «در انتظار صدور ⏳» به «صادر شده ✅» تغییر دهد.
- [ ] **۴. سیستم صدور بلیت هواپیما (نسل جدید پنل پرواز):**
  - [ ] طراحی فرم سریع صدور بلیت با قابلیت انتخاب خودکار مسافر از لیست کاروان‌ها (Auto-fill) یا ورود دستی.
  - [ ] طراحی **پیش‌نمایش زنده بلیت الکترونیکی (E-Ticket / Boarding Pass)** با ظاهر مدرن، لوگوی برند، بارکد، QR Code، اطلاعات کامل پرواز و قوانین.
  - [ ] افزودن دکمه «دانلود / چاپ نسخه PDF» با استفاده از استایل‌های `@media print` و تابع `window.print()` به‌گونه‌ای که در زمان چاپ فقط خود بلیت در صفحه قرار گیرد.
- [ ] **۵. سیستم حسابداری اختصاصی کاروان و طرف حساب‌ها:**
  - [ ] **ماژول سود و زیان کاروان‌ها:** جدول محاسباتی دارای فیلتر ماهانه شامل: نام کاروان، تعداد مسافر، هزینه هتل، قیمت خرید، قیمت فروش و محاسبه پویای سود/زیان خالص با JavaScript.
  - [ ] **ماژول مدیریت طرف حساب‌ها (همکاران و کارگزاران):** جدول وضعیت مالی طرف حساب‌ها با تفکیک رنگی واضح (قرمز برای بدهی، سبز برای طلب).
  - [ ] پیاده‌سازی دکمه **«📄 خروجی صورت‌حساب PDF»** برای باز کردن مودال یا نمای چاپی فاکتور رسمی با جزئیات تراکنش‌ها و قابلیت پرینت/ذخیره PDF.

## فاز ۴: داده‌های نمونه (Mock Data)، تعاملات JavaScript و تست نهایی
- [ ] تولید و تزریق داده‌های نمونه واقعی و بومی (Mock Data) شامل تورهای مشهد، کربلا، استانبول و دبی، هتل‌های معتبر، اسامی مسافران، اطلاعات پروازها و تراکنش‌های مالی.
- [ ] اتصال منطق یکپارچه‌سازی داده‌ها در JavaScript (به‌روزرسانی هم‌زمان آمار داشبورد و جداول حسابداری هنگام ثبت مسافر جدید یا صدور بلیت).
- [ ] بررسی و اصلاح نمایش جداول عریض در صفحات کوچک موبایل (افزودن `overflow-x-auto` و بهینه‌سازی فاصله‌گذاری‌ها).
- [ ] بازبینی نهایی راست‌به‌چین بودن تمامی آیکن‌ها، فلش‌ها، مودال‌ها و تست عملکرد چاپ (Print Layout) برای بلیت هواپیما و صورت‌حساب مالی.
